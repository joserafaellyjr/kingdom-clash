# Stage 1 — Player Mechanics

## Goal
Create the first playable first-person prototype for the commander.

## Included
- First-person camera and mouse look
- WASD movement, sprinting, and jumping
- A simple 3D medieval training courtyard
- On-screen control instructions

## Not included yet
Combat, NPCs, teams, objectives, currency, recruitment, shops, XP, and multiplayer. These belong to later roadmap stages.

| Input | Action |
|---|---|
| W / A / S / D | Move |
| Mouse | Look around |
| Shift | Sprint |
| Space | Jump |
| Esc | Release mouse |
