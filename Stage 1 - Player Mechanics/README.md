# Stage 1 — Player and Frontline Foundation

**Status: First World War prototype**

## Included
- First-person only camera and mouse look.
- Visible first-person weapon prop.
- Right-click aiming, left-click arcade firing, and R reload.
- Shift toggles the portable armor shield; it remains deployed until Shift is pressed again.
- WASD movement and double-tap W sprint.
- A muddy battlefield road between blue and red flag bases.
- Ten friendly and ten opposing soldier models.
- Simple squad movement and abstract arcade combat behavior.
- Health, ammunition, squad counts, and a flag-capture objective.

## Controls
| Input | Action |
|---|---|
| W / A / S / D | Move |
| Double-tap W | Sprint while W is held |
| Mouse | Look around |
| Left click | Fire |
| Right click (hold) | Aim |
| R | Reload |
| Shift | Deploy / retract shield |
| Esc | Pause |

This is an early gameplay foundation. Soldier behavior, models, battlefield details, and combat balance are expected to improve in later iterations. Three.js is loaded from jsDelivr, so an internet connection is required.
